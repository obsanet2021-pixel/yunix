🌐 DEPLOYMENT OPTIONS (Choose ONE)

After testing locally, expose to the internet:

┌─ OPTION A: Cloudflare Tunnel (RECOMMENDED for Production)
│  ✓ Free HTTPS automatically
│  ✓ No port forwarding needed
│  ✓ Custom domain support
│  
│  Setup:
│    cloudflared tunnel create yunix-mcp
│    cloudflared tunnel route dns yunix-mcp api.yunixofficial.com
│    cloudflared tunnel run yunix-mcp
│  
│  Endpoint: https://api.yunixofficial.com/mcp
│  ⏱️  Takes 5 minutes

├─ OPTION B: ngrok (Quick Testing)
│  ✓ Instant deployment
│  ✓ No configuration needed
│  
│  Setup:
│    ngrok http 3000
│  
│  Endpoint: https://xxxx-xxxx-xxxx.ngrok.io/mcp
│  ⏱️  Takes 1 minute

└─ OPTION C: localtunnel (Quick Testing Alternative)
   ✓ Named subdomain
   ✓ Simple setup
   
   Setup:
     npm install -g localtunnel
     lt --port 3000 --subdomain yunix-mcp
   
   Endpoint: https://yunix-mcp.loca.lt/mcp
   ⏱️  Takes 2 minutes

⚡ TROUBLESHOOTING QUICK REFERENCE

  Error: "Missing SUPABASE_URL or SUPABASE_SERVICE_ROLE_KEY"
    → Check .env exists in yunix-mcp-server/
    → Check credentials not empty
    
  Error: "Port 3000 already in use"
    → netstat -ano | Select-String "3000"
    → Stop-Process -Id <PID> -Force
    
  Error: "Health check fails"
    → Run: npm run build
    → Run: npm run start:http
    → Check firewall allows port 3000
    
  MCP tools don't appear in Claude
    → Ensure endpoint is HTTPS (not HTTP)
    → Verify server responds to GET /health
    → Restart Claude Desktop or refresh claude.ai
